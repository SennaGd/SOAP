## Rewrite tweaks into database

### What is a tweak?
A tweak is a sequence of registry changes
that changes the way the system behaves. 
This can be changing a registry key from value 1 -> 0,
which will as an example disable a power saving feature.

### What categories does a tweak have?
A tweak can be split into multiple fragments,
one tweak alone can and will have multiple tweaks inside it.
